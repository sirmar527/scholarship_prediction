# Прогноз стипендии

**Дата формирования:** 15.05.2026 07:29

## На каких данных обучена модель

Модель обучена на данных **9,177** переходов между семестрами (**4,505** студентов). Для проверки качества использовались данные **2,331** переходов (**1,127** студентов) тестовые. 
## Насколько точна модель

На проверочной выборке из 2,331 переходов модель дала правильный ответ в **1,950** случаях и ошиблась в **381** (точность **83.7%**).

Для сравнения: лучший простой метод («rule_no_blocking») даёт точность **83.3%**. Модель превосходит простые правила на **0.3** п.п.

Дополнительные метрики качества: ROC-AUC = **0.920** F1 (macro) = **0.836**.

## Как модель работает по категориям студентов

Каждый студент попадает в одну из четырёх категорий в зависимости от того, была ли у него стипендия сейчас и будет ли в следующем семестре:

- 1. **Была→сохранил** — модель угадывает **96%** таких случаев
- 2. **Была→потерял** — модель угадывает **54%** таких случаев
- 3. **Не было→получил** — модель угадывает **35%** таких случаев
- 4. **Не было→нет** — модель угадывает **95%** таких случаев

**Потеря стипендии:** из 422 студентов, реально потерявших стипендию, модель верно предупредила о 227 (54%). 
**Получение стипендии:** из 162 студентов, впервые получивших стипендию, модель верно предсказала 57 (35%).

## Распределение по уровням риска

Каждому студенту модель присваивает вероятность получения стипендии (от 0% до 100%). На основе этой вероятности студенты делятся на группы:

- **Высокий риск** (вероятность < 30%): **978** студентов (42%) — рекомендуется обратить внимание
- **Средний риск** (30%–60%): **318** студентов (14%) — стоит мониторить
- **Низкий риск** (> 60%): **1,035** студентов (44%) — ситуация стабильная

# Реконструкция структуры ФГОС

**Дата:** 2026-05-13 17:52

**Исходные данные:** 155,295 записей, 5,933 студентов, 345 планов

## Метод

1. Учебные планы объединены в направления через общих студентов (≥3 общих) и пересечение предметов (Jaccard ≥0.3 для планов с одинаковым покрытием семестров).
2. Предметы классифицированы по блокам ФГОС на основе:
   - ВидКонтроля (ГАК/ВКР → Б3)
   - Ключевые слова в названии (практика → Б2)
   - Частота по планам (≥30 планов → Б1.О.General)
   - Peer frequency внутри направления (≥60% → Б1.О.Prof)

### Файлы

- `direction_clusters.csv` — какой план в каком направлении
- `block_mapping.csv` — каждый (план, предмет) → блок ФГОС
- `clusters/cluster_NN.md` — детальный отчёт по каждому направлению

### Как проверять

1. Откройте `clusters/cluster_12.md` (Юриспруденция) — крупнейшее направление
2. Проверьте: все ли профильные предметы в Б1.О.Prof, а не в Б1.В?
3. Если нашли ошибку — исправьте в `block_mapping.csv` (колонка `block`)
4. Затем запускайте `scholarship_predict.py --blocks block_mapping.csv`

### Известные ограничения

- Граница Б1.О/Б1.В точна на ~85-90% (STEM направления хуже)
- Б2 может ложно сработать на предметы со словом 'практика' в названии
- Направления с 1-2 планами и <20 студентами ненадёжны
- Различие Б1.В.ОД / Б1.В.ДВ не реконструируется
